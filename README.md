# Storage Estimator

## Purpose
A Python program that estimates the total storage needed for a number of files, based on the average file size in megabytes (MB).

## How to Run
1. Make sure Python is installed.
2. Open a terminal in this folder.
3. Run:

```
python storage_estimator.py
```

## Example
Input:

```
Number of files: 100
Average file size (MB): 2.5
```

Output:

```
Total storage needed: 250.00 MB
```
